# Thymeleaf

Thymeleaf — серверный шаблонизатор для HTML. Он рендерит **готовую HTML-страницу
на сервере**, подставляя в шаблон данные, и отдаёт её браузеру. Нужен, когда
приложение само отдаёт страницы, а не работает чистым JSON-API для фронтенда.

## Зачем это и где применяется

Есть два подхода к вебу:

- **REST + отдельный фронтенд** (React и т.п.) — backend отдаёт JSON, страницу
  строит браузер. Сейчас это самый частый вариант.
- **Server-side rendering** — сервер сам собирает HTML и отдаёт готовую страницу.
  Здесь и нужен шаблонизатор вроде Thymeleaf.

SSR-подход уместен для сравнительно простых приложений, админок, писем, страниц,
которые отдаёт сам сервер. В Spring MVC Thymeleaf — стандартный выбор.

## Как выглядит

Шаблон — обычный HTML со специальными атрибутами `th:*`, куда подставляются данные:

```html
<h1 th:text="${user.name}">Имя</h1>
<ul>
    <li th:each="order : ${orders}" th:text="${order.title}">Заказ</li>
</ul>
```

- `th:text` — подставить значение в текст элемента.
- `th:each` — цикл по коллекции.
- `th:if` / `th:href` и другие — условия, ссылки, атрибуты.

Особенность Thymeleaf — шаблон остаётся **валидным HTML**: его можно открыть в
браузере как есть (с заглушками), а на сервере атрибуты `th:*` заменятся данными.

## Как работает в Spring MVC

1. Контроллер возвращает **имя шаблона** и кладёт данные в `Model`.
2. Thymeleaf берёт шаблон, подставляет данные, собирает HTML.
3. Готовая страница уходит в браузер.

```java
@GetMapping("/users/{id}")
String userPage(@PathVariable Long id, Model model) {
    model.addAttribute("user", userService.find(id));
    return "user";   // отрендерит templates/user.html
}
```

## Как ответить на интервью

Коротко: Thymeleaf — серверный шаблонизатор HTML для Spring MVC. Он нужен при
server-side rendering, когда сервер сам собирает и отдаёт готовую страницу, — в
отличие от REST + отдельный фронтенд, где backend отдаёт JSON, а страницу строит
браузер. Шаблон — обычный HTML с атрибутами `th:*` (`th:text`, `th:each`, `th:if`),
причём он остаётся валидным HTML и открывается в браузере с заглушками. Контроллер
возвращает имя шаблона и кладёт данные в `Model`, Thymeleaf подставляет их и отдаёт
HTML. Уместен для админок, писем, несложных страниц; для SPA берут REST + фронтенд.
