# Gradle

Gradle — вторая популярная система сборки для JVM, альтернатива Maven. Решает те
же задачи (зависимости, компиляция, тесты, упаковка), но по-другому: вместо
декларативного XML — гибкий скрипт сборки и упор на скорость.

## Чем отличается от Maven

- **Скрипт вместо XML.** Сборка описывается на Groovy или Kotlin
  (`build.gradle` / `build.gradle.kts`) — это программируемый скрипт, а не чисто
  декларативный документ. Гибче, но легче переусложнить.
- **Компактнее.** Объявление зависимостей заметно короче мавеновского XML.
- **Быстрее** за счёт нескольких механизмов: **инкрементальная сборка**
  (пересобирает только изменившееся), **кэш сборки** и **демон** (фоновый процесс,
  не стартует JVM каждый раз).

```kotlin
// build.gradle.kts
dependencies {
    implementation("org.springframework.boot:spring-boot-starter-web:3.3.0")
    testImplementation("org.junit.jupiter:junit-jupiter:5.10.0")
}
```

## Конфигурации зависимостей

Аналог maven-scope, но со своими названиями:

- `implementation` — зависимость для компиляции и рантайма (основная).
- `testImplementation` — только для тестов (JUnit, Mockito).
- `runtimeOnly` — нужна только в рантайме (драйвер БД).
- `compileOnly` — только при компиляции (Lombok).

## Задачи (tasks)

Единица работы в Gradle — **задача**: `build`, `test`, `bootRun`. Задачи связаны
зависимостями (перед `build` выполнится `test`). Команды похожи на Maven:
`./gradlew build`, `./gradlew test`.

**Gradle Wrapper** (`gradlew`) — скрипт в репозитории, который сам скачивает
нужную версию Gradle. Поэтому для сборки не нужен установленный Gradle — достаточно
`./gradlew`, и у всех в команде одна версия.

## Maven или Gradle

- **Maven** — стандартнее, предсказуемее, проще читать (декларативный XML); если
  не нужна гибкость — его хватает.
- **Gradle** — быстрее и гибче, удобен для больших/сложных сборок и Android; но
  скрипт можно переусложнить.

Для стажёра главное — уметь читать оба и понимать, что они делают одно и то же
разными средствами. Выбор обычно уже сделан в проекте.

## Как ответить на интервью

Коротко: Gradle — альтернатива Maven, те же задачи, но вместо декларативного XML —
скрипт на Groovy или Kotlin (`build.gradle`), компактнее и гибче. Быстрее за счёт
инкрементальной сборки, кэша и демона. Зависимости объявляются конфигурациями:
`implementation`, `testImplementation`, `runtimeOnly`, `compileOnly`. Единица
работы — задача (`build`, `test`, `bootRun`), запуск через `./gradlew` — wrapper
сам подтягивает нужную версию. Maven стандартнее и предсказуемее, Gradle быстрее и
гибче; в проекте выбор обычно уже сделан, важно уметь читать оба.
